## Аналитический этап

Материалы находятся в каталоге КТ2: отчёт, модели BPMN и ER, блок-схемы, процедурная программа на Python.

Запуск из корня репозитория: python КТ2/src/main.py КТ2/src/example.json --batch B1. Подробности — в КТ2/src/README.md.
# Реализация на Java

Материалы третьей контрольной точки находятся в `КТ3/`: полный отчёт,
UML в `models/classes.drawio` и `models/classes.png`, исходники и инструкция
`src/java/README.md`, рецензирование и сведения о репозитории.
Нужен JDK 17+, сторонние библиотеки не требуются. Автономная Java-проверка
включает 18 сценариев. Сопоставление с процедурной версией выполнило
56 сценариев; служебный скрипт — `materials/kt3/verify_equivalence.py`.
